# HR Analytics – Employee Attrition Analysis

## Project Overview
An HR Data Analytics project focused on analyzing employee attrition and workforce trends using Python, SQL, and Power BI.

## Project Files

- [**EDA Report**](HR_Analytics_EDA_Report.docx) – Findings, evidence, interpretation, and recommendations.
- [**Cleaned Dataset**](HR_Analytics_Cleaned.csv) – Dataset prepared for analysis.
- [**Original Dataset**](HR_Analytics.csv) – Original HR data, if approved for public sharing.
- [**Python Analysis Notebook**](notebooks/HR_Analytics_Analysis.ipynb) – Data cleaning and exploratory data analysis.
- [**SQL Queries**](sql/HR_Analytics_Queries.sql) – SQL business analysis.
- [**Power BI Dashboard**](dashboard/HR_Analytics_Dashboard.pbix) – Interactive HR dashboard file.

## Tools Used
Python | Pandas | NumPy | Matplotlib | Seaborn | SQL | Power BI | DAX

## Objectives
- Analyze employee attrition rates.
- Compare attrition across departments and job roles.
- Explore overtime, satisfaction, salary, and tenure patterns.
- Provide data-driven HR recommendations.
